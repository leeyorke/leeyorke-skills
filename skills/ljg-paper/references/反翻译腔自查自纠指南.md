# 如何避免翻译腔？翻译腔自查自纠指南

## 翻译腔症状

## 多余的义肢

### 当……的时候

由 “when...” 而来的翻译腔。

“当他看见我回来的时候，他就向我奔来。” VS “看见我回来，他就向我奔来。”

### 在……（方面/上）

源于英文介词 in。

“在鞋的品质方面” VS “鞋的品质”

“在上午上课期间” VS “上午上课期间”

这个要自己斟酌。

### 多余的“地”

由英语副词后缀“-ly”而来的“地”

“不知不觉地就看完了” VS “不知不觉看完了”。

“X然地”，“然”字本就指“……的样子”，属于文言副词的后缀，再加个“地”显得更加不伦不类：

“他愤然地走开” VS “他愤然走开”

### 多余的“着”

源于英语强调的“-ing”进行时。

“靠着打鱼生活” VS “靠打鱼生活”。

“有着很大脾气” VS “有很大的脾气”。

### 多余的“所”

“我所能想到的，都失败了” VS “我能想到的，都失败了”

### 多余的“们”

“先生们” VS “各位先生”

《红楼梦》中就说过“爷们”、“丫头们”，“姑娘们”，但在叙述部分，仍多用“众人”、“众丫环”、“诸姐妹”。

“这批强盗”、“这些学生”、“各地选手”而不是“强盗们”、“学生们”、“选手们”。没有必要全拘于一个“们”字。

“医生们一致认为他已经康复了。“ VS “医生一致认为他已经康复了。”

如果已经使用了“都”、“一致”等词语，它们本就含有“复数”之意，“们”字就多余了，而且也不符合中文习惯。

“人们”一词，纯粹属于无中生有，一般用“大家”、“众人”、“人人”等。

### 多余的“有关”/“关于”

英文“about”/“concerning”的影响。

“我今天上午听到一个有关联合国的消息” VS “我今天上午听到一个联合国的消息”。

“你有关于他的资料吗？” VS “你有他的资料吗？”

### 多余的“作为”

“作为一个中国人，我们怎能不爱中国？” VS “身为中国人，怎能不爱中国？”

### 多余的“作出”

英文中的“make”。

“对于这件事，你们还没有作出决定吗？” VS “这件事你们还没有决定吗？”

“兄弟两个争论了一夜，最后还是哥哥作出让步。” VS “兄弟两个争论了一夜，最后还是哥哥让步。”

### 多余的“存在”

“台北市的交通有不少问题存在。” VS “ [台北市]的交通有不少问题。”

## 滥用

有些词应该克制地使用。

### 过多的“的”

如艾青的“生活在草原上的人们的/岁月的艰辛”。

源于英文中的“of”，即使是英文写作，也要讲究不连用多个“of”。

更恐怖的是，中文里“的”，不仅可以表示所有格，还可以接在形容词后面，表示形容词的词性，这种“的”可有可无。如 [何其芳]的一句：“发现了一束开得正艳丽的黄色的连翘花在我书桌上和一片写着你亲切的语句的白纸”。

### 过多的“和”

源于英文中的常用的“and”。

“李太太的父亲年老和常生病。” VS “李太太的父亲年老而多病（ [李太太]的父亲年老多病）”

“同事们都认为他的设计昂贵和不切实际。” VS “同事都认为他的设计昂贵而不切实际。”。

考虑用“并”、“并且”、“及”、“以及”、“与”、“且”、“而”、“而且”等等来取代，这些词含义丰富得多。有时也可以直接去掉“和”字。

### 过多的“通过”

源于英文的“through”/“by”。

说“通过交涉”却不说“经过交涉”。

### 代词滥用

中文不像英文，英文代词少不得，但中文里代词常常可以省略，而且不影响意思。

“ [花莲]是台湾东部的小城，它以海景壮美闻名” VS “花莲是台湾东部的小城，以海景壮美闻名”

“它”、“它们”，或者开头的“我们”，更需要特别注意。

有时候“它”、“它们”，可以用“这”，“这些”，“那”，“那些”来代替，或者径直指出代替物。如“老王狗倒养了好几只，又不给狗吃饱。”

### 冠词滥用

源于英文中的“the”或“a/an”。在中文中的表现就是滥用“一个”。

### 特定词汇滥用

“证明”“显示”：源于英文的，This proves...,it show等。如“这证明他错了”“这表明了我们准备充分”。

“足够”：说“他有足够的钱养家糊口。”，不说“他的钱够养家了。”

## 追求精确，反遭其害

有时，自以为更精确或更严谨的表达，其实没什么用。

### ……之一

源于“one of”。

“李广乃名将之一。” VS “李广乃汉朝名将。”

“《红楼梦》是中国的文学名著之一。” VS “《红楼梦》是中国的文学名著。”

### 最……之一

源于英文：“one of the most……”。

“李白是中国最伟大的诗人之一。” VS “李白是中国极伟大的诗人（李白是中国的大诗人）”

### 一字一译

如：“family member” 译作 “家庭的一员”、“家庭成员”，却忘了中文有“家人”一词。

## 滥造词语

如无必要，不要生造词语。

### XX性

“这本书 [可读性] 很高。” VS “这本书很耐看/有趣/好看”

“专业性很强。” VS “很专业。”

源于英文中经常通过变换词尾来改变词性，如 -able 变为 -ability。

### XX度

“具有很高的知名度” VS “很有名”

### XX主义

“陆游的作品里存在着极高度的爱国主义精神” VS “陆游的作品富于爱国精神”。

即使是英文写作，也强调少用“-ism（XX主义）”这种词，大而无当。

### XX者

“他是一位长期的素食主义的奉行者。” VS “他吃长素。（他长期吃素）”

源于英文中的 -er 后缀，常译为“XX者”。

## 句式的毛病

### 形容词前饰太长

“我见到一个长得像你兄弟说话也有点像他的陌生男人” VS “我见到一个陌生男人，长得像你兄弟，说话也有点像他。”

### 抽象动词作主语

英文用 [抽象动词] 作主语很自然。但中文却很别扭。

如说“他的不肯就范……”、“我不喜欢他的‘将计就计’”。

### 用名词代动词

用一个“万能”的抽象动词，如“接受”、“进行”、“作出”等等，加上一个名词，来表示动作。

如“做这次旅行”、“作了一次私下谈话”、“作了五年的奋斗”、“进行了为期三日的研究”、“做些什么商谈”、“得到更大的安全”、“进入睡眠状态”、“从事一次航行”。

### 被动句

源于英文中“-ed”被动语气。即使是英文写作中，也是要尽量避免写被动句的。

而且英文中被动语可以没有行为者，但在中文里，用

被动句的毛病有两个： 1. 滥用被动语气取代自然的主动语气 2. 千篇一律只会用“被”字

第一个毛病，只能说要克制，中文里被动语气用得比较少。应该多考虑转换为主动语气。

第二个问题，中文历来就有被动语句，表达方式很多，例如：“给人欺负了”、“叫人欺负了”、“让人欺负了”、“为利所迷”、“他吓得要死”、“挨了一顿打”、“不为酒困”，古文中也有用“见”字表示被动式的。

可以考虑用“受”、“遭”、“挨”、“给”、“叫”、“教”、“让”等等代替。

还有一种情况使用“被”字，更别扭。那就是在被动句中没有“行为者”。例如“他被许可来美”，就没有告诉我们是谁许可的。这种句子在英文中却是很自然的。如果知道“行为者”是谁，不访补上去：“ [美国] 批准他来美。”，或者变换句式，“他已经获准赴美。”。

有一些词是不必加“被”字的。如：“他吓得昏过去了。”、“钟敲了三下。”、“房间已经布置好”。

## 速查表

> “翻译腔”（Translationese）的本质是 **生搬硬套外语的语法结构和词汇习惯，牺牲了中文固有的动态表达、紧凑结构和语感** 。

以下是“反翻译腔词汇与句式速查表”，分为 **高频赘词清理** 、 **动词弱化挽救** 、 **句式结构重塑** 以及 **经典语境反翻示范** 四个维度。

### 一、 高频赘词清理表（能删则删）

翻译腔往往带有大量的“语法垫脚石”，在中文里完全是冗余的。

| **源翻译腔词汇/结构** | **潜在病因** | **替代方案 / 优化策略** | **示例（误 → 正）** |
| --- | --- | --- | --- |
| **作为一个...**  (As a...) | 身份标签冗余 | 直接去调，或改用“身处/担任/对于” | 作为一个程序员 $\rightarrow$ 身为程序员 / 做程序员这行 |
| **当...的时候**  (When...) | 机械对应时间从句 | 删掉“当”或“的时候”，或换用“时”、“之际” | 当我回家的时候 $\rightarrow$ 我回家时 / 回到家 |
| **在...之下/之中**  (Under / In...) | 抽象空间介词泛滥 | 改为具体动词，或直接省略介词 | 在这种情况之下 $\rightarrow$ 这种情况下 / 局势至此 |
| **关于 / 针对**  (About / Regarding) | 强行拉出话题主体 | 用具体动词（如“谈、看、谈及”）或直接去掉 | 关于这个问题 $\rightarrow$ 这个问题 / 谈及此事 |
| **某一个 / 绝大多数的**  (A / Most of) | 滥用冠词和限定词 | 中文非必要不强调单复数，直接删掉冠词 | 我买了一本书 $\rightarrow$ 我买了本书 / 我买书了 |
| **...之一**  (One of the...) | 缺乏最高级的妥协表达 | 改用“算得上”、“数一数二”、“名列前茅” | 他是最伟大的作家之一 $\rightarrow$ 他是数一数二的伟大作家 |

### 二、 动词弱化挽救表（万恶之源：名词化）

英语倾向于使用静态的名词，再用弱动词（如 *make, take, conduct, have* ）去驱动； **而中文是动词主导的语言** 。

| **弱动词组合（翻译腔）** | **英文原型** | **中文标准动态表达** |
| --- | --- | --- |
| **进行** 思考 / **进行** 讨论 | make a conversion / discuss | 思考 / 讨论 / 商榷 |
| **做出** 决定 / **做出** 贡献 | make a decision / contribute | 决定 / 贡献力量 |
| **产生** 影响 / **带来** 改变 | have an impact / bring changes | 影响到 / 改变了 |
| **加以** 拒绝 / **予以** 支持 | give rejection / support | 拒绝 / 支持 |
| **持有**...的看法 | hold the opinion | 认为 / 觉得 |
| **受到**...的欢迎 | receive popularity | 受欢迎 / 大受追捧 |

> **转化逻辑：** 删掉前面的万能动词，把后面的“名词”直接恢复成动词。

### 三、 句式结构重塑表（思维逆转）

除了词汇，句式结构的僵硬是翻译腔的重灾区。

#### 1\. 被动句的祛魅（滥用“被”字）

- **英文习惯：** 强调客观性，大量使用 *Passive Voice* 。
- **中文习惯：** 尽量用主动、主谓倒装，或用“让、叫、挨、受、由、获”等自然字眼代替生硬的“被”。

| **翻译腔（硬用“被”）** | **反翻译腔优化** |
| --- | --- |
| 他的作品 **被** 很多人喜欢。 | 很多人 **喜欢** 他的作品。 |
| 这条法律 **被** 通过了。 | 这条法律 **通过了** 。 |
| 我 **被** 告知今天不用加班。 | **公司通知我** 今天不用加班。 |

#### 2\. 定语过长（“的”字连篇）

- **英文习惯：** 各种后置定语从句（ *which, who, that* ）无限向后延伸。
- **中文习惯：** 短句流、定语前置，如果定语太长，必须 **拆句** 或 **改用主谓结构** 。

| **翻译腔（“的”字火车）** | **反翻译腔优化** |
| --- | --- |
| 这是一个 **由他昨晚在办公室里赶出来的** 方案。 | 方案是 **他昨晚在办公室赶出来的** 。 |
| 他露出了一个 **让人感到不寒而栗的** 微笑。 | 他微微一笑， **让人不寒而栗** 。 |

#### 3\. 因果/条件倒装

- **英文习惯：** 先结论，后条件（If / Because 放在句子后半段）。
- **中文习惯：** **前因后果** ，先交代背景、条件、原因，再出结论。

| **翻译腔（尾巴沉重）** | **反翻译腔优化（前因后果）** |
| --- | --- |
| 我没去， **因为天在下雨** 。 | **因为下雨** ，我就没去。 |
| 如果你不能按时完成， **你将会被惩罚** 。 | 你要是掉链子， **准得挨罚** 。 |

### 四、 经典语境反翻示范（体验对比）

以下是文学、职场及日常交流中，翻译腔与地道中文的直观对撞：

| **场景/英文原文** | **翻译腔表达（字面直译）** | **地道中文（反翻译腔）** |
| --- | --- | --- |
| *I am not following you.* | 我没有在跟随你。 | 我没听懂。/ 我没跟上你的思路。 |
| *It is a matter of time.* | 这是一个时间的问题。 | 迟早的事。/ 只是时间问题。 |
| *She is the last person I want to see.* | 她是我最不想见到的最后一个人。 | 我最不想见到的就是她。/ 哪怕见谁我都不想见她。 |
| *To some extent, it is true.* | 在某种程度上，它是真实的。 | 这话多少有些道理。/ 确实如此。 |
| *Your failure to reply will result in cancellation.* | 你未能做出回复将会导致取消。 | **若逾期未回复，将被视为自动放弃。** |
