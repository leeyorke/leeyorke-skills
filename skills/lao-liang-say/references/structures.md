# 老梁式结构模板库

## 核心大结构：凤头·猪肚·豹尾

```
┌─────────────────────────────────────┐
│  凤头（开场 10-15%）                 │
│  - 标准问候 + 直入主题                │
│  - 三大钩子之一：反常/热点/人物      │
│  - 三句话内抛钩子，不废话            │
├─────────────────────────────────────┤
│  猪肚（主体 70-80%）                 │
│  - 讲一段、评一段，交替推进           │
│  - 剥洋葱四层：现象→背景→人性/利益→升华│
│  - 旁支斜出穿插历史/八卦/典故        │
│  - 每大观点前有铺垫(段子/反差/细节)   │
│  - 关键判断单独成段、前停后停        │
├─────────────────────────────────────┤
│  豹尾（结尾 10-15%）                 │
│  - 收网(点主线) → 升华(上普遍) → 点睛/道别│
│  - 深度主题：诗词收尾 + 人情道别       │
│  - 轻松主题：金句收尾 + 人情道别       │
│  - 干脆利落，不拖泥带水               │
└─────────────────────────────────────┘
```

## 单期推进节奏（标准 6 步法）

### 步骤 1：抛现象/亮话题（凤头核心）
- 直接点出本期要聊的新闻/故事/现象
- 话锋锐利，不绕弯
- **字数占比**：~5%

### 步骤 2：拆背景/讲故事（铺垫）
- 评书方式讲清来龙去脉
- 穿插历史、人物、八卦做"垫话"
- 建立信息密度、制造"这人真懂"感
- **字数占比**：~20%

### 步骤 3：设扣子/悬念（过渡）
- 关键处故意停顿或抛问题
- "那这是为什么呢？""这里头有门道"
- 吊住听众，为抛观点做情绪准备
- **字数占比**：~5%

### 步骤 4：抖包袱/抛观点（核心高潮）
- 铺垫到位后突然亮出判断
- 配段子/反差比喻/生活化类比
- 形成记忆点、制造"膝盖拍响"感
- **字数占比**：~15%

### 步骤 5：夹叙夹议推进（猪肚主体）
- 讲一段故事/事实 → 评一段/析一段
- 故事与观点交替咬合，不让任何一方独占
- 可循环 2-3 次：新事实 → 新观点 → 新事实 → 新观点
- 旁支斜出穿插其中
- **字数占比**：~35%

### 步骤 6：升价值/给导向（豹尾前奏）
- 从具体事件跳到普遍道理
- 落到普通人的生活智慧/价值观/处世态度
- 语气从犀利转语重心长
- **字数占比**：~10%

### 步骤 7：收尾（豹尾）
- 见 closings.md
- **字数占比**：~10%

## 通用万能模板（填空即用）

### 模板 A：社会现象/热点评论类（最常用）

```
【标题】：[反差/悬念/金句式标题]

【凤头】
观众朋友们大家好，欢迎您来到《老梁说》。今天咱聊个[反常现象/热点事件]。
按常理说[常理推断]，可您猜怎么着？[反常事实]。这事儿搁谁身上都得琢磨琢磨：这里头，到底有什么门道？

【猪肚·第一层：现象与故事】
先给大伙还原一下现场。[时间/地点/人物/具体情节]，[细节描写]，看着[表象]。
[旁支斜出：顺嘴说个历史/典故/八卦……咱们转过头说回来]。

【猪肚·第二层：背景与制度】
咱把话扯远一点。这事儿不是一天两天的事，得从[历史背景/制度演变/行业规矩]说起。
[具体年份/事件/数据锚点]，[因果链条]。这就好比[生活化比喻]。

【猪肚·第三层：设扣子+抛观点】
那问题来了：[核心问题]？这里头学问大了。
说白了，[核心判断/第一层观点]。一句话，[极度浓缩金句]。
[配段子/反差/自嘲：这就好比……更有意思的是……]

【猪肚·第四层：深层剖析（利益/人性）】
话又说回来，为啥会这样？咱得往深了挖。
归根到底，拼的不是[表象]，是[利益博弈/人性弱点/深层规律]。
[具体案例/数据/对比支撑]。老话讲得好：[俗语/谚语]。

【猪肚·第五层：换个角度/平衡视角】
话说回来，[对立面/弱势群体/另一面]也有[他们的难处/合理性]。
[平衡性论述，不站队、不极端，但立场坚定]。换个角度看，[新启示]。

【豹尾·升华】
看透了这层，[现象]就不稀奇了。这事儿放在咱们大伙身上，也是一个理：
[普遍启示/生活智慧/处世态度]。看清世情不是为了绝望，是为了[少走弯路/活得通透]。

【豹尾·点睛+道别】
最后，送给大伙一句[诗词/老话/金句]："[引用]"。
[大白话拆解一句，结合主题]。
观众朋友们，天下有缘人，开心愉快、笑口常开、身体健康、万事如意！
```

### 模板 B：历史人物/传记深度类

```
【标题】：[人物名]：[一言以蔽之的评价/反差标签]

【凤头】
观众朋友们大家好。今天咱说个人，叫[人物名]。您可能没听过这名字，但[他干的那件大事/留下的那个局]，您肯定知道。这人一生[评价]，咱今天就把这段尘封往事翻出来，看看[核心看点]。

【猪肚·人生第一站：起步/逆境】
[出生/出身/早年经历]，[具体苦难/转折点]。这时候的他，[关键性格特质初现]。
[旁支：同时代对比人物/背景]。

【猪肚·人生第二站：机遇/抉择】
[关键节点/机遇来临]，面临[抉择]。别人都[常规选择]，他偏[非常规选择]。
说白了，这选择背后是[核心价值观/人性洞察]。这就好比[比喻]。

【猪肚·人生第三站：巅峰/争议】
[巅峰成就/争议事件]，[具体细节]。外界评价[两极分化]。
老梁觉得，[核心判断]。归根到底，[深层逻辑]。

【猪肚·晚年/遗产/影响】
[晚年生活/身后评价/留下的遗产]。最扎心的是[某个细节/一句话]。
这留给后人的[启示/警示/财富]是[什么]。

【豹尾·升华】
一个人一生，到底拼啥？拼的不是[表象]，是[本质]。
[人物]的一生告诉咱们：[普遍道理]。咱们普通人学不来他的[才华/运气]，但能学他的[态度/底线/智慧]。

【豹尾·诗词收尾+道别】
最后，用[诗词/名句]送给[人物]，也送给大伙："[引用]"。
[拆解]。观众朋友们，天下有缘人，开心愉快、笑口常开、身体健康、万事如意！
```

### 模板 C：职场/人生/认知升级类（轻松实用风）

```
【标题】：[痛点直击式标题，如"别再用战术勤奋掩盖战略懒惰了"]

【凤头】
观众朋友们大家好。最近后台好多朋友问老梁同一个问题：[用户痛点/困惑]。
老梁琢磨琢磨，这事儿啊，[反直觉判断]。咱今天不讲大道理，就给大伙[捋一捋/扒一扒]。

【猪肚·误区拆解（讲故事+抛观点）】
先说个误区：[常见错误认知/行为]。
[具体场景故事/案例]。结果呢？[反常结果]。
说白了，[核心观点1]。这就好比[比喻]。

【猪肚·底层逻辑（拆背景+剖人性）】
为啥大伙爱犯这错？咱把话扯远一点。
[心理学/社会学/进化论/博弈论解释]。这里头门道在于[核心机制]。
老话讲得好：[俗语]。

【猪肚·破局方法（给招数+实操）】
那咋办？老梁给大伙支三招：
招儿一：[具体可执行建议]。[原理/案例]。
招儿二：[具体可执行建议]。[原理/案例]。
招儿三：[具体可执行建议]。[原理/案例]。
记住啊，[核心原则金句]。

【猪肚·避坑指南/心态建设】
话又说回来，[提醒/避坑/心态话]。别[错误做法]，要[正确心态]。
更有意思的是，[反直觉小发现/彩蛋]。

【豹尾】
行了，今天就聊到这儿。[一句话总结核心价值]。
最后顺祝老梁的朋友们，天下有缘人，开心愉快、笑口常开、身体健康、万事如意！
```

### 模板 D：短视频/短文案极简版（60-90 秒/500-800 字）

```
【钩子（3秒）】：[反常现象/反问/金句] —— 如"年轻人不加班了，不是懒，是看透了。"

【铺垫（15秒）】：[一个具体故事/数据/现场] + [设扣子："为啥？"]

【观点（20秒）】：说白了……[核心判断] + [生活化比喻]

【深度（15秒）】：归根到底……[利益/人性/规律] + [一句俗语/老话]

【升华（10秒）】：这事儿告诉咱们……[普遍启示]

【收尾（5秒）】：[诗词/金句] + "大伙儿，开心愉快、笑口常开、万事如意！"
```

## 质量自查清单（生成后必检）

- [ ] **结构**：凤头猪肚豹尾完整，六步法节奏清晰
- [ ] **讲评比**：猪肚部分"讲一段、评一段"交替，无连续 3 段纯讲/纯评
- [ ] **判断感**：每个大观点前有铺垫，判断句单独成段、前停后停
- [ ] **语气层**：全文体现 和风→犀利→幽默→温度 四层切换
- [ ] **口语度**：高频引导词(咱说/说白了/归根到底/这就好比/话又说回来)覆盖全文
- [ ] **锚点**：至少 2 个具体年份/数字/情节细节
- [ ] **过渡**：旁支斜出有"咱们转过头说"收回，转场自然
- [ ] **收尾**：深度文必有诗词收尾+拆解+人情道别；轻松文必有金句+人情道别
- [ ] **视角**：全程平民视角，无居高临下、无空洞说教
- [ ] **禁忌**：无书面连接词、无预告、无堆料、无人身攻击
