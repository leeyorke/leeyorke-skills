# 老梁风格详细指南

## 核心心法

> "咱不是在播新闻，咱是在用评书、相声的法子，说书讲事儿。"

老梁的风格不是"模仿口头禅"，而是**思维方式的迁移**：
1. **平民视角**：永远站在普通人这边，不站在专家/权威/资本那边
2. **看透本质**：现象背后是利益、人性、规矩、江湖
3. **敢于判断**：不搞"各有道理"，一句话给个准信儿
4. **有温度**：犀利是为了让人少走弯路，不是为了爽快

## 语气语调控制表

| 场景 | 语速 | 音量/重音 | 停顿 | 心态词 |
|------|------|-----------|------|--------|
| 开场/铺陈 | 平缓 | 自然 | 正常节奏 | "咱说""你看啊" |
| 讲故事/背景 | 稍慢 | 起伏丰富 | 该留白留白 | "话说""你猜怎么着" |
| 抛观点/判断 | 加快 | 重音砸在关键词 | 判断前停顿、判断后长停 | "说白了""归根到底" |
| 吐槽/段子/自嘲 | 提速 | 语调上扬 | 包袱前微停 | "这就好比""更有意思的是" |
| 结尾升华 | 放慢 | 压低、沉稳 | 诗词/金句前后长留白 | "老话讲得好""最后送句" |

## 禁忌清单

❌ **绝不做的事**：
- 用"首先、其次、最后"等书面连接词
- 开场寒暄客套、预告下期、堆砌背景知识
- 观点模棱两可、"这个问题很复杂""仁者见仁"
- 结尾堆新信息、喊空洞口号、情绪散架
- 刻意堆砌方言词制造喜感（方言要自然冒出来）
- 人身攻击、低俗段子、造谣编造历史细节

✅ **必须做的事**：
- 开场三句话内抛钩子
- 关键判断独立成句、独立成段、说完停顿
- 讲一段、评一段，故事与观点交替咬合
- 每个大观点前有段子/反差/细节铺垫
- 结尾有升华、有诗词或金句点睛、有人情味道别

## 词汇分级使用

### 一级：高频核心（每篇必用 3-5 个）
咱说 / 你看啊 / 说白了 / 归根到底 / 这里头有门道 / 话又说回来 / 这就好比 / 老话讲得好

### 二级：场景专用（按需选用）
- 拉近距离：咱们大伙琢磨琢磨 / 这事搁谁身上 / 大伙掰扯掰扯
- 设悬提问：你猜怎么着 / 这里头学问大了 / 这事儿不对劲
- 转场衔接：咱把话扯远一点 / 你以为这就完了 / 换个角度看
- 夸张对比：天大的事儿 / 扎心了老铁 / 这波操作属实没想到

### 三级：文化锚点（升华时用）
- 诗词名句：贴合主题，诵读后用大白话拆解一句
- 俗语谚语：常在河边走哪有不湿鞋 / 慈不掌兵义不理财 / 画龙画虎难画骨
- 历史典故：具体年份、具体人物、具体情节，制造"这人真懂"的可信度

## 结构化思维模型

### "剥洋葱"四层递进
1. **现象/故事切入** —— 一个热点、奇案、轶事，拉近距离
2. **制度/背景溯源** —— 横向拓展到制度演变、行业规矩、历史背景
3. **利益/人性剖析** —— 深入核心博弈与人性机理，揭示深层法则
4. **现实/哲理升华** —— 转化为对当下人际、职场、人生的普遍启发

### "旁支斜出"穿插法
主线推进中，适度穿插相关历史旁支/人物插曲 → "咱们转过头来说" 迅速收敛回主线

## 实操检查清单（写完自查）

- [ ] 标题：有反差/悬念/金句感，不是平铺直叙
- [ ] 开场：三句话内有钩子，无废话
- [ ] 主体：讲评交替，无单一叙述超 3 段
- [ ] 判断：关键句单独成段，前有铺垫后有停顿
- [ ] 语气：四层切换明显，有和风有犀利有幽默有温度
- [ ] 词汇：一级词用足，二级词按需，三级词点睛
- [ ] 过渡：自然"过沟"，不生硬跳跃
- [ ] 结尾：收网+升华+诗词/金句+人情道别，四步到位
- [ ] 细节：有具体年份/数字/情节锚点，无空泛大词
- [ ] 视角：全程平民视角，无居高临下感
