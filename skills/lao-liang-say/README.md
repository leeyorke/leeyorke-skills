# 老梁说

以老梁（梁宏达）的风格写文章/演讲稿/短视频脚本。用户给出主题，skill 输出一篇具备老梁标志性语气、结构、修辞、开场收尾的完整稿件。

## 快速开始

### 1. 直接使用（在支持 skill 的环境中）
```
/lao-liang-say 帮我写一篇老梁风格的文章，主题是年轻人为什么不愿意加班了
```

### 2. 作为提示词工程参考
查看 `scripts/generate.py` 构建的系统提示词 + 用户提示词，复制到任意 LLM 中使用。

### 3. 学习风格参考
- `references/style-guide.md` — 核心风格心法、语气控制表、禁忌清单
- `references/openings.md` — 三大标准开场钩子模板库
- `references/closings.md` — 标准三步收尾 + 诗词匹配速查表
- `references/phrases.md` — 惯用词句式库（4大类引导词 + 5大标志性句式）
- `references/structures.md` — 万能填空模板（A/B/C/D 四种）+ 质量自查清单

## 核心风速览

| 维度 | 关键词 |
|------|--------|
| 人设 | 平民说书人、敢判断时评人、雅俗段子手 |
| 语气 | 和风→犀利→幽默→温度 四层切换 |
| 结构 | 凤头(钩子) · 猪肚(讲评交替/剥洋葱) · 豹尾(收网/升华/诗词/道别) |
| 口语 | 咱说/说白了/归根到底/这就好比/话又说回来/老话讲得好 |
| 句式 | 反弹琵琶(颠覆直觉) / 递进剖析(三层) / 对比反差 / 生活化比喻 / 旁支斜出 |
| 开场 | 反常现象式 / 劲爆新闻式 / 人物故事式 —— 三句话摁住人 |
| 结尾 | 深度必配诗词(拆解) + 人情道别；轻松配金句 + 人情道别 |

## 使用示例

> **输入**：帮我写一篇老梁风格的文章，主题是"年轻人为什么不愿意加班了"
>
> **输出标题示例**：《别拿情怀绑架奋斗，这届年轻人只是看透了》
>
> **输出结构**：
> - 凤头：反常现象开场（按理说年轻该拼，可偏偏不加班了）
> - 猪肚：拆背景(996历史)→设扣子→抛观点(说白了是分配机制坏了)→深层剖析(利益/人性)→换角度(理解企业也理解员工)→给招数
> - 豹尾：升华(看清世情是为了少走弯路)→诗词收尾(得之坦然失之淡然)→人情道别

## 质量标准（生成后自查）

- [ ] 凤头猪肚豹尾完整，六步法节奏清晰
- [ ] 猪肚"讲一段、评一段"交替，无连续3段纯讲/纯评
- [ ] 关键判断单独成段、前停后停，高频引导词覆盖全文
- [ ] 体现和风→犀利→幽默→温度四层语气切换
- [ ] 至少2个具体年份/数字/情节细节锚点
- [ ] 旁支斜出有"咱们转过头说"收回，转场自然
- [ ] 深度文必有诗词收尾+拆解+人情道别
- [ ] 全程平民视角，无居高临下、无书面连接词、无预告堆料
